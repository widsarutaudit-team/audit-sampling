# ระบบสุ่มเลือกตัวอย่างสำหรับงานตรวจสอบ (ด้วยวิธีทางสถิติ)

เครื่องมือสุ่มเลือกตัวอย่างสำหรับงานตรวจสอบ ทำงานในเบราว์เซอร์ทั้งหมด ข้อมูลที่นำเข้าไม่ถูกส่งออกจากเครื่องของผู้ใช้

## ความสามารถหลัก
- วิธีที่ 1 การเลือกตัวอย่างแบบทุกรายการมีโอกาสเท่ากัน (Random Selection) พร้อมตัวเลือกคัดกรองรายการสาระสำคัญ (Key item) และการจัดกลุ่มตามช่วงยอดเงิน
- วิธีที่ 2 การเลือกตัวอย่างแบบถ่วงน้ำหนักตามมูลค่า (Monetary Unit Sampling)
- วิธีที่ 3 การเลือกตัวอย่างแบบช่วง (Systematic Selection)
- นำเข้าข้อมูลจาก Excel / CSV หรือวางจากคลิปบอร์ด
- รายงานผลพร้อมพิมพ์ หรือบันทึกเป็น Excel
- เลือกตัวอย่างเพิ่มเติมจากรายการที่เหลือ
