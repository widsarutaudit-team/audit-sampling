# ระบบสุ่มเลือกตัวอย่างสำหรับงานตรวจสอบ (ด้วยวิธีทางสถิติ)

เครื่องมือช่วยคำนวณขนาดตัวอย่างและเลือกรายการตัวอย่างตามหลักสถิติสำหรับงานตรวจสอบ ทำงานในเว็บเบราว์เซอร์ทั้งหมด ไม่ต้องติดตั้งโปรแกรม ใช้ได้ทั้ง macOS และ Windows (Safari, Chrome, Edge)

> **ข้อมูลไม่ออกจากเครื่องของผู้ใช้** ระบบอ่านไฟล์และประมวลผลในเบราว์เซอร์เท่านั้น ไม่มีการส่งข้อมูลการตรวจสอบไปยังเซิร์ฟเวอร์ใด ๆ และไม่จัดเก็บข้อมูลหลังปิดหน้าเว็บ

| `index-offline.html` | ดาวน์โหลดเก็บไว้ในเครื่อง แล้วดับเบิลคลิกเปิด ใช้ได้โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต (มีตัวอ่าน Excel และ PDF ในไฟล์) |

## ความสามารถหลัก

### วิธีการสุ่มตัวอย่าง
- **วิธีที่ 1 Random Selection** — ทุกรายการมีโอกาสถูกเลือกเท่ากัน เลือกคัดกรองรายการสาระสำคัญ (Key item) ก่อนสุ่ม และเลือกสุ่มแบบจัดกลุ่มตามช่วงยอดเงินได้
- **วิธีที่ 2 Monetary Unit Sampling (MUS)** — รายการที่มีมูลค่าสูงมีโอกาสถูกเลือกมากกว่า
- **วิธีที่ 3 Systematic Selection** — เลือกรายการตามช่วงห่างที่เท่ากัน

ขนาดตัวอย่าง = (ประชากรคงเหลือ ÷ ค่าการแสดงข้อมูลที่ขัดต่อข้อเท็จจริงที่ยอมรับได้ [MAT]) × Confidence Factor ปัดขึ้นเป็นจำนวนเต็ม

### การนำเข้าข้อมูล
- อัปโหลดไฟล์ **Excel (.xlsx, .xls)**, **CSV** (ภาษาไทยทั้ง UTF-8 และแบบที่บันทึกจาก Excel) และ **PDF** ที่มีข้อความ เช่น รายงานบรรทัดรายการบัญชีแยกประเภทจาก GFMIS ซึ่งระบบกระทบยอดกับยอดรวมท้ายรายงานให้อัตโนมัติ
- **วางข้อมูลจาก Excel** โดยตรง (⌘+V / Ctrl+V)
- ระบบหาแถวหัวตาราง คอลัมน์เลขที่เอกสาร คอลัมน์จำนวนเงิน และแถวรวมท้ายไฟล์ให้อัตโนมัติ ผู้ใช้ตรวจสอบและแก้ไขได้
- **ตารางข้อมูลแบบ Excel** — ตรวจและแก้ไขข้อมูลหลังนำเข้า แทรก/ลบแถว และย้อนการแก้ไขได้ ระบบกระทบจำนวนรายการและยอดรวม ณ ตอนนำเข้ากับข้อมูลที่ใช้สุ่ม และบันทึกทุกการแก้ไขไว้ในรายงาน

### การกำหนดประชากร
- เลือกใช้เฉพาะรายการบวก เฉพาะรายการติดลบ หรือทั้งบวกและติดลบ (ค่าสัมบูรณ์) รายการยอดศูนย์ไม่นำมาใช้
- จำนวนประชากรทั้งหมดและจำนวนประชากรที่เป็นสาระสำคัญ เลือกคิดแบบค่าสุทธิ ค่าสัมบูรณ์ หรือกรอกเองได้
- รายการสาระสำคัญ: ให้ระบบคัดกรองตามค่า MAT หรือเกณฑ์ที่กำหนดเอง ระบุเลขที่เอกสารที่ตรวจแล้วเอง หรือสุ่มจากรายการสาระสำคัญ

### รายงานและการสอบทาน
- รายงานแสดงพารามิเตอร์ การคำนวณ และรายการที่เลือกทั้งหมด พิมพ์หรือบันทึกเป็นไฟล์ Excel ได้
- **เลขอ้างอิงการสุ่ม (Seed)** — ทุกการสุ่มมีเลขอ้างอิงแสดงในรายงาน ผู้สอบทานนำข้อมูลชุดเดิม ค่าเดิม และเลขอ้างอิงเดิมมาสุ่มซ้ำได้ผลเหมือนเดิมทุกรายการ
- **ล็อกผลการสุ่ม** — หลังได้รายงาน ทุกขั้นตอนเปิดดูได้แต่แก้ไขไม่ได้ เพื่อให้ข้อมูลที่เห็นตรงกับรายงาน
- **เลือกตัวอย่างเพิ่ม** จากรายการที่ยังไม่ถูกเลือก พร้อมบันทึกเหตุผลและเลขอ้างอิงแยกแต่ละครั้ง

## ขั้นตอนการใช้งาน

1. **ข้อมูลหัวรายงานและเลือกวิธี** — กรอกหน่วยงาน หน่วยรับตรวจ ปี และชื่อบัญชี แล้วเลือกวิธีการสุ่มตัวอย่าง
2. **นำเข้าข้อมูล** — อัปโหลดไฟล์หรือวางข้อมูล ตรวจการจับคู่คอลัมน์ ตารางข้อมูล และยอดรวมกับงบทดลอง
3. **กำหนดค่า** — กรอก MAT และ Confidence Factor ตรวจจำนวนประชากรและรายการสาระสำคัญ
4. **สรุปและเริ่มสุ่ม** — ตรวจกล่องสรุป แล้วกด "เริ่มทำการสุ่มรายการ"
5. **รายงาน** — พิมพ์หรือบันทึก Excel เก็บไว้ในกระดาษทำการ พร้อมเลขอ้างอิงการสุ่ม

คู่มือฉบับเต็มอยู่ในเมนู "คู่มือการใช้งาน" ภายในระบบ

## ข้อควรทราบ

- ตรวจยอดรวมของข้อมูลที่นำเข้ากับงบทดลองหรือรายงานต้นฉบับทุกครั้ง โดยเฉพาะข้อมูลจากไฟล์ PDF ซึ่งระบบกำหนดให้ผู้ใช้ยืนยันการตรวจสอบก่อนสุ่ม
- ไม่รองรับ PDF ที่เป็นภาพสแกน
- การพิสูจน์ผลด้วยเลขอ้างอิงเดิม ควรใช้ระบบเวอร์ชันเดียวกับตอนสุ่ม จึงควรเก็บไฟล์ `index-offline.html` ของเวอร์ชันที่ใช้ไว้คู่กับกระดาษทำการ
- ระบบเป็นเครื่องมือช่วยเลือกตัวอย่างเท่านั้น การใช้ดุลยพินิจทางวิชาชีพและการสรุปผลเป็นความรับผิดชอบของผู้ตรวจสอบ
